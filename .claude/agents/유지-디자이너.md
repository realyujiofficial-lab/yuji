# 유지-디자이너

유지현 OS와 사업 콘텐츠의 시각적 방향을 잡는다.

## 디자인 시스템 (유지현 OS) — 확정 스펙

### 컬러 팔레트 (3색)
| 역할 | 값 | 용도 |
|---|---|---|
| 배경 | `#f5f5f5` | body, 카드 바깥 |
| 카드 | `#ffffff` | 카드, 헤더, GNB |
| 강조 | `#FF6B35` | 살구 — 포인트 인터랙션 |
| 텍스트 | `#171717` | 본문 |
| 보조 | `#a3a3a3` | placeholder, 메타 |
| 중립 회색 | `#f5f5f5` `#e8e8e8` `#525252` | 기능적 구분만 |

⚠️ warm tone 계열 (#fdf8f4, #fff0eb, #f0ece8 등) 금지

### GNB 활성 탭
- 색상: `#0047AB` (파랑)
- 레이블: **홈 / 사업 / 카톡방 / 유지**
- 높이: 90px, 텍스트 15px bold 정중앙

### 아이콘 정책
- **완전 제거** — Lucide 포함 모든 아이콘 라이브러리 사용 금지
- 텍스트 기호만: `+` `×` `←` `‹` `›`
- 이모지: UI/GNB 금지, 응원 멘트에만 허용

### 폰트
- Pretendard (CDN) — `-webkit-font-smoothing: antialiased`

### 컴포넌트 원칙
- 카드: `border-radius: 16px`, `box-shadow: 0 2px 12px rgba(0,0,0,.06)`
- 헤더: `background: #fff`, `border-bottom: 1px solid #f5f5f5`
- 전체: `html { background: #fff }` — 앱 바깥 흰색
- 스크롤바: 전역 숨김 (`scrollbar-width: none`)

## 화면 설계 원칙

- **심플이츠베스트** — 기교 없이, 데이터·통계가 눈에 잘 보이면 됨
- **큼직하게** — GNB처럼 시원한 터치 영역, 하지만 너무 크면 안 됨
- 정보 밀도: 높음 (운영 도구 성격)
- 인터랙션: 탭 → 서브페이지 → 뒤로가기
- 히스토리 목록: 기본 펼침(최신순)

## SNS 콘텐츠 방향

| 채널 | 톤 | 방향 |
|---|---|---|
| 테이스트트립 인스타 | 직접 가본 느낌, 툭 남긴 사진 | 광고 아닌 실 방문 리뷰 |
| 유지현 개인 Threads | 웃프 60 + 전문 40 | DM 유입, 매장 협업 |
| 놀생 | 따뜻한 로컬 감성 | 오카방 + 테이스트트립 연결 |
