## 카톡방 대시보드

- `okaband.html` iframe 없음 → index.html에 인라인 통합
- `data.json`을 `fetch('data.json?t='+Date.now())`로 로드
- Chart.js CDN: `cdn.jsdelivr.net/npm/chart.js@4/dist/chart.umd.min.js`
- data.json 구조: `all_dates[]`, `daily{}`, `user_stats{}`, `at_risk{}`, `recent_7d_avg`
- 공지·이슈 히스토리: 기본 펼침(`.open` 클래스), 최신순 정렬

## 핵심 규칙

- 색상 기교 금지 — 흰/검정/살구 외 warm tone (#fdf8f4 등) 사용 금지
- 회색은 기능적 중립톤만 (#f5f5f5, #e8e8e8, #a3a3a3)
- GNB 서브페이지 진입 시 부모 탭 active 유지
- safe-area: `env(safe-area-inset-bottom)` 반드시 반영
- data.json 수정 시 같이 `git add data.json` 추가
