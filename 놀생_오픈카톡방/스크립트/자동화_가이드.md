# 오카방 운영 자동화 가이드

> 마지막 업데이트: 2026-05-18

---

## 전체 흐름

```
카톡 대화 복붙
    ↓
Claude Code에 붙여넣기 → 분석 + 파일 저장
    ↓
sync_to_vercel.sh 실행
    ↓
GitHub push → Vercel 자동배포 → yuji-seven.vercel.app 반영
```

---

## 1. 대화 분석 (Claude Code)

카톡 대화 복사해서 Claude에게 붙여넣으면서:

> "오늘 대화 추가해주고 분석해줘"

Claude가 자동으로:
- `대화기록/원본/YYMMDD_대화기록.txt` 에 내용 추가
- `_workspace/stats.json` 업데이트
- 이슈 있으면 `운영/이슈/` 폴더 생성
- 운영방안/히스토리 MD 업데이트

---

## 2. Vercel 동기화 (수동 1번)

분석 끝나면 터미널에서:

```bash
bash "/mnt/c/Users/ryu53/Downloads/yuji os/깃허브/harness-main/놀생_오픈카톡방/스크립트/sync_to_vercel.sh"
```

하면 자동으로:
1. `stats.json` → `okaband-dashboard/data.json` 복사
2. GitHub 커밋 & 푸시
3. Vercel 1~2분 후 반영

---

## 3. 파일 구조 (어디에 뭐가 있는지)

```
놀생_오픈카톡방/
├── 대화기록/
│   └── 원본/          ← 카톡 원본 TXT (YYMMDD_대화기록.txt)
├── _workspace/
│   └── stats.json     ← Claude가 분석해서 만드는 통계 JSON
├── 운영/
│   ├── 이슈/          ← YYMMDD_이슈명/ 폴더로 관리
│   └── 운영방안/      ← 운영 히스토리, 이벤트 아이디어 MD
└── 스크립트/
    ├── sync_to_vercel.sh   ← Vercel 동기화 스크립트
    └── process_chat.py     ← 대화 파싱 (대량 처리 시 사용)
```

```
okaband-dashboard/           ← Vercel에 배포되는 레포
├── data.json               ← stats.json 복사본 (이게 사이트에서 읽힘)
└── okaband.html            ← 대시보드 UI
```

---

## 4. 이슈 발생 시 처리

이슈가 생겼을 때 Claude에게:

> "[이슈명] 이슈로 추가해줘"

생성되는 것:
- `운영/이슈/YYMMDD_이슈명/` 폴더
- `YYMMDD_이슈_팩트정리.md`
- `YYMMDD_이슈_모니터링.md` (추방·분란 등 경과 추적용)
