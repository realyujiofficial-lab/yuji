> 생성: 2026.05.17 | 데이터 기반 + 설문 반영

## 1. 계절 테마별 오카방 커버사진 교체

> 방의 첫인상 = 커버사진. 계절감 있는 커버로 활성 멤버 귀속감 + 신규 유입 자연 유인.

| 시즌 | 교체 시기 | 이미지 콘셉트 |
|---|---|---|
| **봄** | 3월 초 | 벚꽃+로컬 카페 / 봄나물 한상 / 꽃놀이 도시락 |
| **여름** | 6월 초 | 해수욕장 회+매운탕 / 루프탑 맥주 / 계곡 밥상 |
| **가을** | 9월 초 | 단풍 맛집 드라이브 / 가을 한우 / 국밥+낙엽 감성 |
| **겨울** | 12월 초 | 첫눈+따뜻한 국물 / 연말 야경 맛집 / 온천+맛집 코스 |
| **연말/신년** | 12월 말~1월 초 | 새해 소원+이 방에서 올해도 잘 먹겠습니다 감성 |

**실행 방법:** 무료 Canva로 제작 가능. 방 이름 + 슬로건 ("진짜 경험을 나누는 사람들") + 계절 사진 합성.

## 2. 지역 현지인 릴레이 (월 1회 고정)

> 설문 1위: "현지인 추천 여행 정보 강화"

**방식:**
1. 방장이 매월 1일 or 15일에 특정 지역 지목
2. 해당 지역 닉네임 멤버에게 @태그로 릴레이 요청
3. "이번 주 릴레이 지역: 전주!" → 전주 멤버들 맛집/카페/코스 공유

**예시 공지:**
```
🗺 이번 달 릴레이 지역: #인천
@인천 남동구/로컬/라이언 @인천/야호 @인천/올라운더 @인천남동/맛집/호호부는튜브

인천 살면서 진짜 가는 맛집/카페/핫플 공유해주세요!
관광객 말고 현지인이 가는 곳!
```

## 3. 계절 특집 핫플 공지 (분기 1회)

> 설문 3위: "축제·시즌 한정 정보"

| 시기 | 공지 내용 |
|---|---|
| 봄 (3~4월) | 벚꽃 명소별 현지인 맛집 코스 (진해/여의도/경주) |
| 여름 (7~8월) | 이 여름 꼭 가야 할 계곡/해변 + 근처 밥집 |
| 가을 (10~11월) | 단풍 드라이브 코스 + 중간 들러야 할 곳 |
| 겨울 (12~1월) | 연말 야경 맛집 + 온천 지역 현지 추천 |

## 4. 소규모 번개 모임 (분기 1회)

> 설문 5위: "소규모 여행 모임 (당일, 1박2일)" — 6명 원함

**형태:**
- 당일치기: 서울~수도권 멤버 중심, 특정 지역 맛집 투어
- 1박2일: 방 방향에 맞는 지방 여행지 (예: 전주, 군산, 제주)
- 오픈 모집: 방에 공지 → 카카오폼 신청 → 10명 이하 소규모 진행

---

## 5. 주간/월간 맛집·여행 뉴스 뽑기

> 외부 정보를 방에 녹여 신선도 유지 + 화제 유발

**뉴스 소스:**
- 유튜브: "현지인 맛집" "로컬 맛집" 키워드 최신 영상 → 조회수/댓글 반응 높은 것
- 트위터(X): #맛집 #핫플 #여행 실시간 트렌드
- 네이버 블로그: 지역별 최근 1개월 인기 맛집 포스팅

**뽑는 방식 (에이전트 활용):**
1. 아래 형식으로 텍스트 붙여넣기
2. "이번 주 뉴스 뽑아줘" 입력
3. 에이전트가 지역별 핫이슈 3~5개 + 카카오방 공유 문구 작성

**방 공지 활용 예시:**
```
🗞 이번 주 여행/맛집 뉴스

🔥 제주 이호테우 해변 근처 흑돼지 골목 재조명
🍜 부산 서면 "숨은 라멘" 유튜버 4명 연속 픽
☕ 전주 한옥마을 카페 신규 오픈 → 웨이팅 없는 시간대 공유 요청!

→ 다녀온 분 후기 공유 대환영!
```

## 6. 핵심 기여자 감사 멘트 (월 1회)

> 뭉이도사, woo, 먹위일 등 정보 기여자 이탈 = 방 질 즉시 하락

**방식:**
- 매월 말 or 분기 1회
- 그 달 정보 많이 공유한 멤버 3~5명 이름 + "덕분에 이 방이 살아있습니다" 공지
- 강요 아닌 자연스러운 인정 → 잔류 동기 부여

## 7. 지역별 추천 아카이브 구축

> 설문 2위: "지역별로 정리된 추천 아카이브" — 9명 원함

**방식:**
- 카카오톡 톡게시판 or 오픈채팅 공지 링크
- 시트 or 노션으로 지역/카테고리별 정리
- 멤버가 공유한 URL 주기적으로 수집해서 추가

**카테고리 예시:**
```
서울 - 성동/강남/종로 맛집
경기 - 수도권 당일 코스
부산/대구 - 지방 원정 코스
제주 - 현지인 추천 (관광지 제외)
```

## 8. 비활성 멤버 정기 정리 (연 1~2회)

> 2024.05 사례: 312명 강퇴 후 방 활성도 오히려 상승

**주의사항 (3월 이슈 반면교사):**
- 대량 @멘션 → 알림 폭탄 → 피로감 → 이탈 유발
- 닉변 요청은 **공지로만** (개인 @태그 X)

- 강퇴 전 공지 1주일 전 예고 권장

## 에이전트 활용 가이드 (주간/월간 텍스트 분석)

### 어디에, 어떻게 텍스트를 주면 되나?

**카카오톡 대화 내보내기 방법:**
```
오픈채팅방 → 메뉴(≡) → 대화 내보내기 → 텍스트 파일 저장
```

**에이전트에게 주는 방법:**

1. **Claude Code (지금 이 환경):**
   - 저장된 `.txt` 파일을 아래 경로에 넣기:
     ```
     /mnt/c/Users/ryu53/Downloads/깃허브/harness-main/놀생_오픈카톡방/대화내용/
     ```
   - 파일명 예시: `260601~260630_대화기록.txt`
   - Claude에게: "이번 달 대화 분석해줘. 이슈 징조 있어?"

2. **직접 붙여넣기:**
   - Claude 대화창에 해당 주/월 텍스트 복사해서 붙여넣기
   - "이 텍스트 분석해줘. 이슈 사전 신호 찾아줘" 요청

---

### 주간 분석 요청 템플릿

```
[이번 주 대화 텍스트 붙여넣기]

위 대화에서:
1. 이슈 사전 신호 있어? (불만/갈등/이탈 조짐)
2. 누가 가장 정보 기여 많이 했어?
3. 반응 좋았던 주제는?
4. 자진 퇴장한 사람 있어? 직전에 무슨 일 있었는지?
```

### 월간 분석 요청 템플릿

```
[이번 달 대화 파일명: 260601~260630_대화기록.txt]

이번 달 분석해줘:
- 주별 퇴장 수 (이상 징후 있는지)
- 정보 기여 TOP 5
- 반응 높은 주제 TOP 3
- 주의 멤버 있는지 (방향 안 맞는 발언 반복)
- 이벤트 타이밍 추천
```

### 이슈 사전 감지 키워드 (에이전트가 자동 탐색)

| 카테고리 | 키워드 예시 | 의미 |
|---|---|---|
| **불만/불쾌** | "불편", "현타", "왜 이런", "분위기", "저런 분" | 멤버 간 갈등 조짐 |
| **방 방향 이탈** | "수다", "개인 얘기", "친목", "사적" | 방 정체성 흔들림 |
| **이탈 예고** | "나갈게", "조용히", "여기 맞나", "잠깐 나가" | 자진 퇴장 전 신호 |
| **과시/갈등** | "저도 버는데", "호텔", "페라리", "명품" | 위화감 유발 발언 |
| **갈등 직접** | "왜 그러세요", "기분 나빴", "좀 그렇지 않나요" | 멤버 간 마찰 |
