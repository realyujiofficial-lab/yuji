# 오카방 운영 히스토리

## 1. 오카방의 시작 방향

**"현지인 정보 아카이브형 커뮤니티"**
직접 다녀온 경험 기반의 맛집·핫플·여행 정보를 함께 나누는 방

핵심 방향:
- 실제 경험 기반 정보 공유
- 집단지성형 맛집·여행 정보
- 장소 중심 대화
- 광고/체험단성 분위기 배제
- 정보 흐름 유지
- 적당한 온기 + 과도한 친목 지양

구체화한 운영 요소:
- 공지 정리
- 질문 가이드
- 장소 공유 양식
- 이벤트 운영
- 인증 절차

---

## 2. 점점 느껴진 방향성 차이

운영 중 기울어지던 흐름:
- 특정 인물 중심 분위기
- 과도한 친목
- 개인 만남 중심 흐름
- 정보보다 관계 중심 대화

대응 방식:
- 방 목적 설명
- 운영 방향 안내
- 정보 중심 흐름 요청
- 분위기 완충

→ 감정적 폭발이 아닌, 설명·기다림·고민 끝에 운영 기준으로 판단

---

## 3. 옴팡님과의 방향 차이

**옴팡님이 느낀 것:**
- 방 분위기가 점점 경직된다
- 운영 방식이 답답하다
- 만나기 전 정보 공유를 "보고서 같다"고 표현
- 운영 기준·모임 규칙에 부담감

**방 정리 이후 공개 발언 (원문):**
- "독재"
- "방의 실체"
- "기만"
- "왜 사람들이 떠나는지 생각해보라"

**운영자 입장:**
- 사람 자체를 미워해서 정리한 것이 아님
- 오카방 원래 방향과 달라지는 흐름을 운영 차원에서 정리한 것

---

## 4. 인간적 감정과 운영 판단은 별개

인간적으로는 아쉬움이 있었다.
함께 이야기 나누고, 정이 들고, 방 분위기를 같이 만들었던 사람들이었기 때문에.

하지만:
> "정이 들었다" ≠ "방향까지 포기한다"

운영 과정: 기준 수립 → 설명 → 기다림 → 방향 공유 → 운영 기준으로 정리
기준 없이 휘두른 운영이 아니었다.

---

## 5. 운영 핵심 원칙

| 원칙 | 내용 |
|---|---|
| 정보 기준 | 경험 기반, 장소 중심 흐름 유지 |
| 분위기 | 말투는 부드럽게, 과도한 친목 지양 |
| 안전성 | 방향성 유지 |
| 운영자 역할 | 모든 사람 만족 X → 커뮤니티 방향 유지 O |

---

## 6. 이번 일을 통해 느낀 점

- 자유로운 친목을 원하는 사람 vs 정보 중심 커뮤니티를 원하는 사람
- 오카방은 후자를 선택
- 절대적 잘못이 아닌 **원하는 커뮤니티 형태의 차이**
- 멤버가 떠난 것도 서로 니즈가 달라서 어쩔 수 없는 부분

---

## 7. 앞으로의 운영 방향

- 경험 기반 정보
- 로컬 감성
- 집단지성 아카이브
- 정보 중심 흐름

사람을 공격하거나 감정적으로 대응하기보다,
운영 기준과 방향을 중심으로 안정적으로 커뮤니티를 만들어가는 것이 목표.
