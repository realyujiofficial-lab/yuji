```
│   ├── 설문조사/      멤버 대상 설문 원본 파일 (.xlsx)
│   ├── 운영방안/      설문 결과 반영 내용, 운영 히스토리, 분석 문서
│   └── 이슈/          사건별 폴더 — 팩트 정리 + 대응 기록
│
├── 데이터/
│   ├── 닉네임_매핑.txt    닉네임 변경 이력 (원본→정규화명 매핑)
│   └── 유저_추적.xlsx     멤버 입퇴장 이력, 활동 추이
│
└── 스크립트/
    ├── process_chat.py    원본 → 정제본 변환 (시스템 메시지 제거, 닉네임 정규화, 연도별 병합)
    └── create_excel.py    대화 데이터 → 엑셀 통계 파일 생성
```

## 대화기록: 원본 vs 정제본

두 폴더는 **같은 대화 데이터**지만 목적이 다르다.

| 항목 | 원본 | 정제본 |
|---|---|---|
| 출처 | 카카오톡 앱 직접 내보내기 | `process_chat.py` 가공 결과 |
| 기간 단위 | 수집 시점 기준 날짜 범위 | 연도 기준 통합 |
| 포함 내용 | 시스템 메시지, 입퇴장 알림, 날짜 구분선, 원본 닉네임 | 대화 메시지만, 닉네임 정규화 적용 |
| 파일 크기 | 더 큼 (2022: 111K / 2023: 1.3M / 2024: 2.3M) | 약 25~30% 작음 (2022: 84K / 2023: 1MB / 2024: 1.6M) |
| 용도 | 재가공 소스, 특정 날짜 추적 | 분석, AI 입력, 통계 처리 |

**원본을 남겨두는 이유:**
- 닉네임 매핑 수정하거나 필터 기준 바꾸면 원본에서 재가공 필요
- 특정 사건 날짜 전후 로그를 날짜 범위로 바로 찾을 때 원본이 편함
- `.eml` 파일은 이메일 내보내기 형식으로 동일 내용이나 별도 보관
