# 오카방 운영 스킬

놀생 오픈카톡방의 공지 작성, 이슈 대응, 이벤트 기획, 성장 전략, 주간 분석을 지원하는 스킬.

## 대화 분석 자동 파이프라인 (핵심 워크플로우)

> 유지현이 카톡 대화를 붙여넣으면 아래 순서로 전부 처리한다. 확인 없이 바로 실행.

```
[1] 대화 파싱
    날짜 감지 → YYMMDD 확정
    참여자/메시지수/시간대/토픽 추출

[2] 파일 저장
    대화기록/원본/YYMMDD_대화기록.txt 에 추가 (없으면 생성)
    기존 파일 끝에서 이어지는지 확인 후 append

[3] stats.json 갱신
    _workspace/stats.json 의 해당 날짜 entry 업데이트
    필드: msgs, users, user_list, sample_texts, topics, peak_hours, issue_flag, ops_note

[4] 이슈 감지
    이슈 신호 있으면 → 운영/이슈/YYMMDD_이슈명/ 폴더 자동 생성
    이슈 다음날 분석 → 운영/이슈/YYMMDD_이슈명N일차/ 폴더 생성

[5] 운영 기록 업데이트
    운영/운영방안/260516_오카방_운영히스토리.md 에 일지 추가
    운영/운영방안/전체분석_로그기반.md 에 일일 분석 추가

[6] 분석 리포트 출력
    참여자/지표/시간대 흐름/주요토픽/이슈/운영 제안 포함
```

**처리 후 안내:**
```
완료 후 Vercel 반영하려면:
bash "놀생_오픈카톡방/스크립트/sync_to_vercel.sh"
```

## 이슈 N일차 추적 규칙

> **큰 이슈만** N일차 추적. 작은 이슈(단발 불만, 일회성 비매너)는 발생일 기록만.

### 큰 이슈 판단 기준 (하나 이상이면 N일차 추적)
- 추방/강퇴 발생
- 공개 비난·분란 발언
- 대규모 이탈 조짐 (하루 3명 이상)
- 방 정체성을 흔드는 반복 행동
- 운영자가 공지로 대응한 건

### N일차 폴더 구조

| 일차 | 폴더명 패턴 | 생성 내용 |
|------|-----------|---------|
| 발생일 | `YYMMDD_이슈명/` | 팩트정리.md + 발언대응기록.md |
| +1일 | `YYMMDD_이슈명1일차/` | 모니터링.md (분위기/이탈 경과) |
| +2~3일 | `YYMMDD_이슈명2일차/` | 추가 이탈 여부, 안정화 여부 |
| 종결 | 마지막 모니터링.md에 "종결" 표시 | 이상 없으면 3~5일차에 종결 |

**종결 기준:** 이탈 없음 + 방 분위기 정상화 + 이슈 언급 없음 3일 연속

## 오카방 핵심 정체성

> **"현지인 정보 아카이브형 커뮤니티"**
> 직접 다녀온 경험 기반의 맛집·핫플·여행 정보를 함께 나누는 공간

| 원칙 | 내용 |
|---|---|
| 정보 기준 | 실제 경험 기반, 장소 중심, 광고·체험단 배제 |
| 분위기 | 말투는 부드럽게, 과도한 친목·연애수다 지양 |
| 운영자 역할 | 모든 사람 만족 X → 커뮤니티 방향 유지 O |
| 성장 방향 | 좋은 정보가 모이면 사람이 따라온다 |

## 1. 주간/월간 대화 분석

> 사용자가 대화 텍스트를 붙여주면 아래 체크리스트로 분석 후 출력한다.

### 이상 신호 체크리스트 (위험 순서)

| 신호 | 판단 기준 |
|---|---|
| 🔴 삭제 메시지 급증 | 평소보다 2배 이상 |
| 🔴 특정 멤버 공개 갈등 발언 | "왜 그래", "나갑니다", 직접 비난 |
| 🟡 수다/연애/개인 얘기 흐름 지속 | 3일 이상 |
| 🟡 외부인 "여기 수다방?" 반응 | 1건 이상 |
| 🟡 자진 퇴장 2명 이상/주 | |
| 🟢 방향 공지 후 정보 공유 증가 | 긍정 신호 |

### 분석 출력 형식

```
## 이번 주 오카방 분석

**이상 신호:**
- 🔴/🟡/🟢 [내용]

**주요 발언 (이슈 될 수 있는 것):**
- [닉네임]: "[발언]" — [평가]

**이번 주 분위기 요약:**
[한 줄]

**추천 액션:**
1. [즉시 할 것]
2. [이번 주 안에 할 것]
3. [다음 달 생각해볼 것]
```

## 2. 이벤트 기획

> 방 정체성을 강화하면서 참여를 높이는 이벤트 유형

### 이벤트 유형별 템플릿

#### A. 지역 맛집 릴레이
```
이번 주 [지역] 특집입니다! 🗺️
직접 가봤던 맛집/카페/핫플 자유롭게 공유해주세요.
장소명 + 짧은 한 줄 후기면 충분해요!
```

#### B. 계절/테마 특집
- 봄: 벚꽃/피크닉 맛집, 여름: 해수욕장 근처 로컬식당
- 가을: 단풍 명소 근처 카페, 겨울: 뜨끈한 국밥/찜류
```
[계절] 이맘때 생각나는 곳 한 군데씩 공유해요! 🍂
```

#### C. 현지인 추천 퀴즈
```
이 지역 현지인만 아는 숨은 맛집은? 🔍
힌트: [힌트1], [힌트2]
맞히신 분께는 제가 아는 비밀 핫플 하나 공유할게요!
```

#### D. 여행 코스 공유
```
[지역] 1박2일 코스 짜본 분 있으세요?
경험 기반 코스 공유해주시면 아카이브에 넣어둘게요 🗂️
```

### 이벤트 시기 추천

| 시기 | 추천 이벤트 |
|---|---|
| 1~2월 | 겨울 핫플, 실내 카페 특집 |
| 3~5월 | 봄 여행지, 꽃구경 코스 |
| 6~8월 | 여름 바다/계곡, 피서지 로컬식당 |
| 9~11월 | 단풍 여행, 가을 축제 근처 맛집 |
| 12월 | 연말 분위기 카페, 한 해 베스트 맛집 |

## 3. 성장 전략

> 분란 없이 사람이 많이 들어오고 만족하는 방 만들기

### 멤버 유입 원리

```
좋은 정보 → 정보 방문자 추천 → 유입
이슈 없음 → 기존 멤버 유지 → 신뢰도
이벤트 → 참여감 → 잔류율 상승
```

### 현재까지의 성장/이탈 패턴 (이슈 분석 기반)

| 원인 | 결과 |
|---|---|
| 광고 계정 유입 | 즉시 이탈 다수 |
| 수다/연애 흐름 지속 | 정보 중심 멤버 이탈 |
| 운영 방향 불명확 | 이질 멤버 유입 + 갈등 |
| 방 분리(수다방) 후 공지 미흡 | 정보방 방향 희석 지속 |

### 성장 액션 리스트

- [ ] **공지 주기화**: 월 1회 "이 방의 정체성" 공지 (너무 자주 X)
- [ ] **베스트 정보 아카이브**: 좋은 정보 톡게시판에 고정
- [ ] **신규 환영 멘트 자동화**: 입장 시 정체성 설명 1줄
- [ ] **계절 이벤트**: 분기 1회, 정보 공유 유도
- [ ] **유도 심문 금지**: 멤버끼리 개인 만남 확인 X

## 4. 공지 작성

공지는 **부드럽지만 방향이 명확**하게.

| 상황 | 대응 |
|---|---|
| 방 방향 재공지 | 정체성 + 歡영하는 정보 + 열린 마무리 |
| 친목/수다 흐름 | 자연스럽게 정보 화제 전환 |
| 이탈 멤버 | 언급 없이 조용히 인정 |
| 이슈 후 안정화 | 짧고 기준 중심 공지 |

**공지 초안 → `references/공지템플릿.md` 참조**

## 5. 이슈 대응

**대응 순서:**
1. 팩트 정리 (누가, 언제, 뭐라고)
2. 운영 기준과 대조
3. 공개 대응 / 조용히 정리 / 무대응 결정
4. `이슈/YYMMDD_이슈명/` 폴더에 기록

**대응 원칙:**
- 잘잘못이 아닌 "커뮤니티 형태 차이"로 프레이밍
- 감정적 반박 없이 기준 중심 마무리
- 재입장 후 비난 → 무대응이 최선

**이슈 전체 기록 → `이슈/오카방_이슈_전체정리.md`**
